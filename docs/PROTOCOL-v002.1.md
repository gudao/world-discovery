# 协议修正案 v0.2.1（阶段 4：环境硬化）

状态：**已冻结（2026-10-10，任何 stage-4 测试世界运行之前定稿）**。本修正案只修改环境与判定条款，不改 v0.2.0 的机制定义（粒子假设集合、矩匹配信息增益、ε 验证分支语义、读者后验统一评分、双记账）。

## 依据

v0.2.0 阶段 1 注册判定：环境过便宜条款触发（fixed = 0.995 ≥ 0.95，所有策略 ~1.0，见 `runs/v002-discrimination/report.md`）。当前方块环境中区分不是瓶颈：解析族误差极小、7 档力均匀可及，任何包含一两次强推的序列都能完成辨识。

## 设计目标

让信息增益在动作间强烈不均，使"挑选区分动作"成为成绩的决定因素。三个杠杆：

1. **观测噪声**：单次试探的信噪比被压低，必须积累多次测量并挑选高增益动作；
2. **细粒度动作网格**：最优试探位置（静摩擦阈值附近）落在粗网格的档位之间，自适应选择优于任何固定档位组合；
3. **更小参数差**：世界对差异接近噪声底，浪费试探的策略无法在预算内补齐证据。

## 修改条款

1. **观测噪声（传感器规格，属先验知识）**：`obs = clean + N(0, σ_obs)`，σ_obs = [0.005, 0.08]（x：5 mm；v：0.08 m/s），每次观测独立抽取，施加于试探期观测与试探后观测。
2. **有效似然噪声**：Δ 由两个含噪观测相减，σ_total = sqrt(σ_family² + 2·σ_obs²)，其中 σ_family 沿用 v0.2.0 校准程序（训练分布、真参数、×1.2 膨胀）。σ_total 同时用于读者似然、IG 评分与可辨识性筛选。
3. **动作集**：25 档力，[-12, +12] 步长 1（含 0），持续时间不变（0.15 s）。
4. **预算**：probe_budget = 8。
5. **世界对**（每种子 40 对，5 种子）：
   - friction 层（20 对）：两世界均 moving，|Δμ| ≥ 0.15 且 |Δm| ≤ 0.08（归因护栏）；
   - mass 层（20 对）：两世界均 moving，|Δm| ≥ 0.30 且 |Δμ| ≤ 0.05；
   - fixed 型移除。理由：本噪声水平下单次强推对固定性仍以 ≫ 6σ 分离，不构成瓶颈维度；如实记录，不代表固定性维度永远无研究价值。
6. **基线策略**：
   - `random`：25 档均匀随机；
   - `fixed7`：v0.1 经典扫描 [0, −12, −6, −2, 2, 6, 12] 循环至预算（阶段 1 的强基线，档位级覆盖最优的固定方案）；
   - `v01_active`：冻结负对照（v0.1 输出方差代理 + 局部记忆）；
   - `ig`：粒子信息增益评分（σ_total，λ = 0.05，ε = 0.15 重复上一步语义）。
7. **可辨识性筛选（evaluator 侧，松）**：75 个干净查询标签上 D = Σ_query Σ_dim (y1−y2)²/(2σ_total²) ≥ 8 nats。仅排除原则上无望的对；不保证预算内可达。
8. **判定（全部预注册）**：
   - 过便宜条款：fixed7 ≥ 0.95 → 不做策略排名，环境仍不足以检验原则；
   - 过难条款（本修正案新增）：四策略最大准确率 < 0.60 → 判环境过难（区分落于噪声之下不可达），不做策略排名；
   - 及格线不变：IG 绝对准确率 ≥ 0.85，对 fixed7 配对优势 ≥ 0.10；未达则按失败解读路径处理（审计评分日志与粒子族误差，修正后用新采样世界对重测，不回调阈值）。
9. **不变项**：N = 200 粒子、λ = 0.05、ε = 0.15、σ_family 校准程序与种子、读者后验统一评分、逐对配对 + 种子级 t CI、绝对数优先、双记账（交互数 + force_time_effort）、负结果照报。

## 冻结前的先验估计（非调参依据，仅记录设计时的量级判断）

- friction 层每试探信号上限 ≈ Δμ·g·Δt = 0.15·9.81·0.15 ≈ 0.22 m/s，σ_total,v ≈ sqrt(0.042² + 2·0.08²) ≈ 0.17（注：若 σ_obs,v = 0.08，此处按冻结值 0.08 计算）；8 次最优试探的两简单假设判别正确率约 0.9+，非最优分配将显著下降——目标区间。
- mass 层信号对 (m, F) 位置敏感（∂Δv/∂m = −F·Δt/m²），筛选会过滤低敏感对；预计该层对多数策略偏易，分层报告承载解释。

（注：条款 1 的冻结值为 σ_obs = [0.005, 0.08]；上文先验估计即按此值计算。）
