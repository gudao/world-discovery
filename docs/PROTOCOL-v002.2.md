# 协议修正案 v0.2.2（阶段 5：信息稀缺域区分测试）

状态：**已冻结（2026-10-11，任何 stage-5 测试世界运行之前定稿）**。本修正案只修改环境与判定条款，不改 v0.2.0 的机制定义（粒子假设集合、矩匹配信息增益、ε 验证分支语义、读者后验统一评分、双记账）。

## 依据

v0.2.1 阶段 4 注册判定：及格线未通过（IG 对 fixed7 优势 +0.095 < 0.10），且 **random ≈ IG（0.995 vs 0.990）**——细网格均匀随机即持续激励，该域瓶颈在贝叶斯读出而非动作选择（见 `runs/v002-stage4/report.md`）。由此得到的定律式结论：**信息增益试探的价值空间在信息稀缺域**。阶段 5 把环境推入该域，检验 R1' 的试探选择条款在稀缺域是否真实承重。

## 先验信息底计算（冻结依据，2026-10-11，任何 MuJoCo 测试世界运行之前完成）

方法：**族内合成模拟**——解析 Coulomb 族同时充当环境真值与读者模型（MuJoCo 由 `analytic_rollout` 替代），观测噪声按候选规格注入，四策略（random / fixed7 / ig / oracle_greedy）在同一套冻结机制上运行。oracle_greedy 是知晓两个真值、每步贪心最大化两假设判别信息的作弊上界。全部代码 `src/world_discovery/prior_floor.py`，全部扫描条件存档 `runs/v0022-prior-floor/prior_floor.json`（30 对/层 × 2 种子 × 7 条件）。

| --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| G1 | [0.005, 0.10] | 重 | 0.808 | 0.817 | 0.900 | 0.900 | 29.5 |
| G2 | [0.005, 0.12] | 重 | 0.742 | 0.767 | 0.858 | 0.875 | 26.4 |

设计结论（全部来自上表，冻结前确立）：

1. **速度噪声单独不产生稀缺**。G1–G3、G6 中 oracle_D 保持 20–30 nats，ig−random 优势 ≤ +0.12；σ_v=0.20 时（G6）四策略一起塌缩——速度通道对所有人都饱和，不构成动作选择的承重差异。
2. **位置噪声是稀缺的约束杠杆**。σ_obs,x 从 0.005 提到 0.02（G4/G5），oracle_D 从 ~26 掉到 6.9–9.6 nats，ig−random 优势升到 +0.15–0.18。位置通道（Δx 累积）原本是 random 也能免费收割的信息源。
3. **重/高摩擦层是必要条件**。CTRL（轻质量层，stage4 式采样）oracle_D = 331 nats，random 0.908——轻质量放大携带速度信号，环境保持信息富裕。**v0.2.1 报告中草案方向（m ≤ 0.9 高敏感区）经计算被推翻：高敏感 = 高信号 = 不稀缺；稀缺域需要重质量。**
4. **族内 ig（0.942）超过真值感知的贪心 oracle（0.850）**。全后验上的矩匹配 EIG 是比两假设贪心判别信息更好的设计准则（后者只看两个真值、且贪心短视）。此为机制层面的正面证据，但注意族内模拟对 ig 偏乐观（读者模型=真值）。
5. 重/高摩擦世界（μ∈[0.4,0.7]、m∈[1.0,1.6]）的静摩擦阈值 μmg ≈ 4–11 覆盖力网格大部分档位：从静止出发的大多数动作零信息，浪费试探代价真实——这正是"挑动作"承重的物理机制。

**选择 G4**：σ_obs = [0.02, 0.12]（σ_total = [0.0288, 0.1778]），重层参数，预算 5。族内 ig−random = +0.184，random 0.758 ≤ 设计目标 0.75（边界），ig 绝对 0.942。

## 修改条款

1. **观测噪声**：σ_obs = [0.02, 0.12]（x：2 cm；v：0.12 m/s）。σ_total = sqrt(σ_family² + 2σ_obs²)，σ_family 沿用 v0.2.0 校准程序（训练分布、真参数、×1.2 膨胀；复现值 [0.0052, 0.0530]）。σ_total 同时用于读者似然、IG 评分与可辨识性筛选。
2. **预算**：probe_budget = 5。
3. **动作集**：25 档力 [-12, +12] 步长 1（含 0），持续时间 0.15 s，与 v0.2.1 相同。
4. **世界对**（每种子 40 对，5 种子 [41–45]）：
   - friction 层（20 对）：两世界均 moving，m ∈ [1.0, 1.6]，μ ∈ [0.4, 0.7]，|Δμ| ≥ 0.12 且 |Δm| ≤ 0.06（归因护栏）；
   - mass 层（20 对）：两世界均 moving，m ∈ [1.1, 1.6]，|Δm| ≥ 0.25 且 |Δμ| ≤ 0.03；
   - fixed 型沿用 v0.2.1 移除决定。
5. **可辨识性筛选（evaluator 侧，松）**：75 个干净查询标签上 D = Σ_query Σ_dim (y1−y2)²/(2σ_total²) ≥ 4 nats（较 v0.2.1 的 8 nats 放宽——稀缺域中 75 查询的可达 D 本身更低；仍仅排除原则上无望的对）。
6. **基线策略**：random（25 档均匀）、fixed7（[0, −12, −6, −2, 2, 6, 12] 循环至预算 5）、v01_active（冻结负对照）、ig（σ_total，λ = 0.05，ε = 0.15 重复上一步语义）。oracle 不进入 MuJoCo 实验（需同时知晓两个真值，仅作族内参照）。
7. **判定（全部预注册）**：
   - 过难条款：四策略最大准确率 < 0.60 → 判环境过难，不做策略排名；
   - 及格线：**IG 绝对准确率 ≥ 0.80 且对 random 配对优势 ≥ 0.10**（对 fixed7 的配对优势作为次要指标报告）；
   - 未达则按失败解读路径处理：审计评分日志与粒子族误差，修正后用新采样世界对重测，不得回调阈值。
   - 门槛出处（冻结时点记录）：0.80 = 族内 ig 0.942 − 0.14 族误差余量（保守；族内模拟对 ig 偏乐观）；0.10 = v0.2.1 及格线连续性。**这两个数字来自先验计算而非任何 MuJoCo 测试结果。**
8. **实现注记（语义等价变更，2026-10-11）**：`analytic_rollout` 与 `information_gain` 向量化（单次批量调用替代逐候选循环）。数学公式与 v0.2.0 冻结版逐字相同，仅浮点求和顺序不同；等价性由 `tests/test_prior_floor.py::test_information_gain_equivalence`（1e-12 nats）验证。阶段 4 已提交结果由变更前的代码产出，其 manifest 哈希如实记录。
9. **不变项**：N = 200 粒子、λ = 0.05、ε = 0.15、σ_family 校准程序与种子、读者后验统一评分、逐对配对 + 种子级 t CI（T=2.776）、绝对数优先、双记账（交互数 + force_time_effort）、负结果照报。

## 偏差风险披露（必须记录）

1. **向假设对齐的实验者自由度**：本环境是在看到"random 在 v0.2.1 环境足够好"之后、针对其弱点（免费收割位置通道与持续激励）设计的考题。对冲：本修正案在任何 MuJoCo 测试运行前冻结；先验信息底计算与全部扫描条件（含不利条件 G6 与 CTRL）永久留档；若 MuJoCo 运行中 random 仍与 ig 打平，该结论照报——那将说明稀缺域结论不迁移出族内模拟。
2. **族内乐观偏差**：先验计算中读者模型=环境真值，ig 的 0.942 是上界。MuJoCo 族误差可能压缩所有策略的绝对准确率（门槛已留 0.14 余量），也可能不同策略地压缩（无先验证据）。
3. **扫描即调参**：7 个条件中选了 G4。所有条件连同未选条件一起存档；选择标准（oracle_D 进入个位数 nats 且 ig−random ≥ 0.15）先于看到 MuJoCo 结果确立。
