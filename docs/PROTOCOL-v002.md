# 实验协议 v0.2

状态：**已冻结（v0.2.0，2026-10-10）**。第 8 节数值已定稿；此后所有阈值不因任何测试结果回调。任何测试世界运行之前定稿。

## 0. 定位与冻结声明

- v0.1 全部输出（`examples/`、manifest、`docs/PROTOCOL.md`）视为冻结，只读。v0.2 代码进新文件，配置进 `configs/v002-*.json`，输出进 `runs/v002-*/`。
- v0.2 检验的是设计原则的**实质**：已有表征无法稳定解释后果时，系统能否找到区分不同解释的试探；解释持续失败时，能否增加有迁移价值的新区分。v0.1 只验证了机制顺序（局部更新先行、门控、成本、数据隔离），v0.1 的负结果（active 输出方差代理被 fixed 支配、动作分布坍缩至 ±12）归因于假设集合 H 未被显式表示，不在本版重跑中"修复"，而是替换为下述显式机制后正面检验。

研究问题重述：

- **R1'（区分）**：显式假设后验上的信息增益试探，能否把旧表征视为相同、真值不同的世界对区分开，并优于随机与固定扫描？
- **R2'（诊断与修正）**：持续失配被检出后，系统能否在并列候选（更新参数 / 延长记忆 / 改噪声模型 / 新增变量）中按预注册判据接受正确的一个？
- **R3'（新区分的迁移）**：被接受的新变量能否从少量历史推断、并迁移到同分布新世界（排除"多存数据"解释）？

## 1. 机制定义：显式假设集合 H

**假设族（先验已知形式、未知参数）**：滑动方块的解析动力学

- 运动时：`m·a = F − μ_k·m·g·sign(v)`，z 方向同理；
- 静止且 `|F| ≤ μ_s·m·g`：不动；
- fixed 世界：任何受力都不动。

参数 `(m, μ_k, μ_s, fixed)` 是隐藏量，真值仅存在于 `evaluator_only_worlds.json`。

**表示**：粒子集合 `{(m_j, μ_j, fixed_j), w_j}`，N=200，先验覆盖训练参数范围（`train_mass`、`train_friction`）。

**反作弊边界（硬约束）**：解析形式属于系统先验掌握的"物理常识"，等价于 v0.1 中"知道输入是 (v, F, Δt)"这一层知识；**参数值不得从任何测试真值校准**。评估器反事实接口与测试世界真值对试探选择、粒子初始化、阈值一律不可见。

**概率语义**：`e_t = −log p(o_{t+1} | h_t, a)` = 粒子加权预测分布上的观测负对数似然（高斯，σ 由训练残差校准，逐输出维度）。一次交互后粒子重加权 + 系统重采样。

**局部记忆的关系**：v0.1 的局部残差记忆保留，定位降级为"解析假设族之外的残差修正器"。总预测 = 解析模型（按粒子加权）+ 局部残差。这保持了与 v0.1 的连续对照：`active/none` 对应纯粒子解析模型，`active/small` 对应解析 + 残差。

## 2. 试探选择：信息增益评分

对每个候选动作 a（沿用 7 档力 × 统一持续时间，可加等待）：

```
score(a) = Ê_o~p(·|a,H) [ H_post(参数后验) 的预期熵下降 ] − λ·C(a)
```

粒子近似：候选动作下粒子预测的散布 + 观测噪声 σ 决定预期后验收缩；实现可用矩匹配或二次近似，具体近似方式写死在代码注释并在结果目录留评分分解日志（每个候选的熵增益、成本、最终得分三项分列，供事后审计评分是否按预期工作）。

- **成本量级校准（预注册）**：λ 取值使"最优区分动作的信息增益"与"最大力动作成本"之比约为 10:1。v0.1 的 `cost_weight=1e-4` 量级失效（成本项上限 ~2e-4，被方差项淹没）是已确认缺陷，本条为其修正。
- **结构化基础探索（预注册 ε=0.15）**：基础探索预算不再均匀随机，而是用于**验证性复测**——以 ε 概率重复执行当前后验最不确定的那个区分动作。依据：原则中"几个模型可能一起自信地犯错"的补丁，检验噪声与漂移，而非盲目抖动。

对照策略（全部保留 v0.1 定义，不重调）：`random`、`fixed`（按序扫描 7 档力）、`v0.1-active`（输出方差代理，原样冻结作为"代理失败"的阴性对照）。

## 3. 判据一：区分测试（R1'）

**世界对构造**（evaluator 侧完成，不泄漏）：

1. 从测试分布采样候选 w1、w2（moving 世界，参数连续采样）；
2. 筛选条件 A：v0.1 冻结全局模型在 21 个标准查询上对两世界的预测差 < ε_pred（旧表征视为相同）；
3. 筛选条件 B：隐藏参数差异 ≥ δ（如 `|μ1−μ2| ≥ 0.15` 或 `|m1−m2| ≥ 0.4`，或一静一动）；
4. 构造 40 对，分摩擦差、质量差、固定差三型各记录。

ε_pred 取 v0.1 冻结模型在验证世界上预测分布的标准差（使"视为相同"有量化含义）；δ 已冻结：`|μ1−μ2| ≥ 0.20`、`|m1−m2| ≥ 0.5`（各自区间的约 37%）、或一静一动。可辨识性筛选（evaluator 侧）：21 标准查询标签中至少 2 个查询上两世界标签差 ≥ 6σ，排除解析上不可分的参数对。

**指标**：预算（12 次真实试探）内，试探序列结束后：

- 主指标：后验判别准确率 `P(正确指认两世界的参数序)`，逐对记录；
- 次指标：两世界后验的对称 KL、终态预测 NMSE。

**报告**：绝对准确率 + 逐对配对差值（IG − fixed、IG − random、IG − v0.1-active）+ 种子级 95% CI，按世界对类型分层。fixed 与 random 是必须战胜的基线，不是陪跑。

**预注册及格线（已冻结）**：IG 策略绝对准确率 ≥ 0.85，且对 fixed 的配对优势 ≥ 0.10（绝对准确率差）。另设环境检查条款：若 fixed 自身准确率 ≥ 0.95，直接判"环境区分过便宜"，进入第 7 节阶段 4 的环境升级，不做策略间排名。理由：5 种子 × 40 对 = 200 个配对二元试验，0.10 优势的检验功效充足（配对差 SE ≈ 0.03）；0.85/0.10 保持强门槛，同时为解析假设族的首次落地留合理实现容差。

**预注册失败解读**：

- 若 IG 与 fixed 都 ≥ 0.90：环境区分仍然太便宜，结论是"环境不构成对原则的检验"，下一步升级环境（第 7 节阶段 4），**不得**调评分宣称胜利；
- 若 IG < fixed 且 < 0.90：评分实现或假设族有错，审计评分分解日志定位，修正后用**新采样的世界对**重测；
- 若 v0.1-active 显著劣于 IG：确认"代理失败"归因，v0.1 负结果闭环。

## 4. 判据二：迁移测试（R3' 的区分部分）

在 w1 上收敛的粒子后验，用于同参数区间、不同实例的 w3：

| 组 | 设置 | 排除的解释 |
| --- | --- | --- |
| A | 冷启动 + 同样试探预算 | 基线 |
| B | w1 的原始交互数据重放给 w3 的局部记忆 | "只是多存了数据" |
| C | w1 的粒子后验迁移 + 剩余预算试探 | 参数级区分的迁移 |

指标：w3 上达到 NMSE 0.02 所需的真实交互次数（学习曲线横轴）。判定：C 显著少于 A 且少于 B（配对，种子级 CI），才承认"区分被迁移"。B 与 C 都热启动但机制不同，是"记忆量"与"参数后验"的机制分离对照。

## 5. 判据三：新区分的提出与接受（R2'/R3' 的概念部分，最小版本）

**失配注入**：训练与校准只见连续滑动摩擦谱（`μ_s = μ_k`）；测试引入 `μ_s = 1.3·μ_k` 的 stick-slip 世界。解析假设族对此持续失配（v0.1 的 B 实验显示 wide 容量有收益而 grow 判据失效，本条把"该扩什么"从容量换成有物理内容的候选）。

**候选池（预注册枚举，v0.2 不做开放式生成）**：

1. 更新 (m, μ) 粒子（参数解释）；
2. 延长局部记忆窗口（记忆解释）；
3. 增大观测噪声 σ（噪声解释）；
4. 新增离散变量 u_stick：静/动摩擦分离阈值模型（新概念解释）。

**触发与判定**：连续两次新数据 prequential 负对数似然超阈值触发诊断；候选在**触发后新到来**的诊断交互流上比较（不复用保留段——v0.1 已确认的选择偏差源）。接受判据沿用 MDL 工程形式：`L_newdata 改善 > β·ΔC + δ`，β、δ 定稿时冻结。

**u_stick 的检验（这是"新概念"的最低门槛，缺一不可）**：

- 可推断性：在其他 stick 世界上，从 ≤ 3 次历史试探推断 u_stick 状态的准确率 ≥ 0.90（对照：v0.1 冻结模型无从推断）；
- 反事实价值：接受 u_stick 后，同一状态不同力档的跨动作反事实预测误差显著下降（用 evaluator 反事实接口评分，不用于训练）——这是对最初研究主张的因果层检验，优先于任何聚合指标；
- 迁移：满足第 4 节的 C > A 且 C > B。

## 6. 统一采样与统计规则

- **分层**：所有测试集 fixed/moving 各半；主表按层报告再报总体。区分测试只用 moving 对。
- **种子**：训练种子 ≥ 5（42–46），**种子是统计单位**。世界级配对差先世界内配对、再跨种子聚合，报种子级 t 分布 95% CI。禁止跨种子挑选最优配置。
- **绝对值优先**：所有表格先报绝对数与逐世界/逐对分布，比值类（×、%）只作次要注释。
- **双记账**：每次比较同时按交互次数与 `force_time_effort` 记账；主要结论必须在 effort 匹配的对照下仍然成立（v0.1 中 active 成本 16.2 vs fixed 9.3 的教训）。
- **负结果照报**：所有阶段结果（含失败）进实验记录；失败数据不得再用于调阈值后当作独立验证。

## 8. 已定稿数值（2026-10-10 冻结，任何测试运行之前）

1. **及格线**：IG 绝对准确率 ≥ 0.85；对 fixed 优势 ≥ 0.10；fixed ≥ 0.95 触发环境过便宜条款（见第 3 节）。
2. **世界对参数差 δ**：`|Δμ| ≥ 0.20` 或 `|Δm| ≥ 0.5 kg` 或一静一动，加 ≥ 6σ 可辨识性筛选（见第 3 节）。
3. **成本与判据**：λ = 0.05 nats/单位 effort（典型最优动作 IG ≈ 0.9 nats，最大力动作成本 |F|·Δt = 1.8，成本占比 10%，对应协议第 2 节的 10:1 校准）；MDL 判据（阶段 4）β = 0.001 nats/参数、δ_MDL = 0.05 nats。**σ 校准程序**：在训练分布上以真参数运行解析模型对照 MuJoCo，取残差标准差 × 1.2 膨胀因子（防粒子在族误差上坍缩）；σ 只在训练世界估计，任何测试真值不参与。
4. **粒子数 N = 200**；阶段 1 动作集与 v0.1 完全一致（7 档力 × 统一时长）。不加"等待"：force=0 已在集合中，等待的判别价值在阶段 4 的 stick-slip 观察中才出现，阶段 1 引入只会增加无谓设计面。

## 8.1 实现澄清（定稿时一并冻结）

- **ε 分支语义**：ε = 0.15 的基础探索为"重复上一步动作"（验证可复现性、检测漂移），第一步时退化为均匀随机。评分分支为信息增益 argmax。
- **阶段 1 种子单位**：v0.1 冻结模型（`examples/quick-A/model.npz`）承担"旧表征"，无再训练，因此阶段 1 的种子 = 世界对采样流 + 策略 RNG 流（5 个种子）。训练种子作为统计单位自阶段 2 生效。此偏差如实记录于结果。
- **阶段 1 IG 策略形态**：纯粒子解析模型（对应 v0.1 中 `active/none` 的位置），不含局部残差记忆；"解析 + 残差"组合留待阶段 2 与 v0.1 机制复跑对照时引入。
- **评分近似**：信息增益用矩匹配形式 `0.5·Σ_dim log(1 + Var_w(粒子预测)/σ²)`（Gaussian-mixture moment-matching 的标准近似），每个候选动作的熵增益、成本、总分分列写入评分日志。

## 9. 边界（v0.2 明确不声称的事）

- 新区分限定于预注册枚举的候选池；"自主提出新概念"的开放式生成推迟至封闭版本跑通。
- u_stick 学到的是静/动摩擦分离这一物理内容，不声称等于人类"摩擦"概念。
- 方块 + x/z 滑动的场景只检验原则的机制链，不外推到通用智能。
