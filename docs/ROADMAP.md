# 迭代路线

## v0.1 已实现

- MuJoCo 接触、摩擦、质量及固定约束环境。
- CPU 神经网络集成，bootstrap + Adam。
- 局部残差记忆与按需容量启用。
- 随机、固定、主动策略；A/B 对照。
- 世界配对评估、完整交互日志、模型保存和源代码哈希。
- 无渲染可运行，桌面查看器可选。

## v0.2 优先做实验可信度

1. 多种子结果自动聚合，以训练种子为统计单位。
2. 分层采样 fixed/moving，单独报告每类表现。
3. 用新到来的诊断数据检验扩展，避免重复保留段选择。
4. 允许局部突变，验证变化检测而不只是冷启动适应。
5. 加更长历史适配器、等总参数模型、不同预算和动作成本对照。

## v0.3 学习表征

把固定随机局部特征换成可训练隐变量编码器。隐变量只能从历史推断，训练损失结合多步预测与容量约束；新世界检查少样本适应。

重要：大网络的现有隐层可能已经有足够表达能力，额外维度的收益不必然意味着发现了新物理因子。先比较更新状态、延长记忆、更新参数、增大容量四种解释。

## v0.4 多模态主动感知

- 由 MuJoCo renderer 获取图像，图像替代理想位置速度输入。
- 加触觉/接触传感器和显式传感成本。
- 动作包含镜头移动、接触、推力、等待时长。
- 将观测噪声和模型未知分开，防止追逐随机噪声。

## v0.5 表征扩展与知识整合

- 多个解释不满足时提出新潜在模块。
- 从少量试探推断模块状态。
- 用不同环境验证迁移，再整合到长期模型。
- 检查灾难性遗忘、概念冗余和容量增长上限。

## 每次迭代记录

在实验记录中填：假设、改动、基线、预算、调参数据、未见测试范围、种子、指标、计算成本、失败案例。一次只改变一个主要机制。保留负结果，不用失败数据反复调参再称为独立测试。
